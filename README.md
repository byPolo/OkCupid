# OkCupid - Data Science Project
To be able to run code without problems please check out the data with this url: https://www.kaggle.com/datasets/andrewmvd/okcupid-profiles
## Decoding Connection: A Sociological & ML Analysis of Dating Data
An investigation into the intersection of education, belief, and relationship intent using the OkCupid dataset.

## 📖 Project Overview
This project explores the underlying patterns of human behavior within a digital dating ecosystem. The analysis is divided into two primary pillars:

- The Sociological Lens: A statistical investigation into how educational attainment influences religious identity and devotion.

- The Behavioral Archetype Model: An Unsupervised Machine Learning pipeline designed to cluster users into "Relationship Personas" based on demographics and natural language processing (NLP).

## 📊 The Dataset
The analysis utilizes a subset of the OkCupid Profiles Dataset, containing roughly 60,000 anonymized profiles.

Context: Data was collected from users of a dating application.

Key Features: Age, Education, Religion, Offspring status, and several open-ended Essay responses.
